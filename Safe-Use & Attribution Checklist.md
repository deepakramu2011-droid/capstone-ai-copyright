Educational checklist for CSE students. Not legal advice. Laws and contract terms differ by country and change over time.

## Before using an AI tool

- [ ] Identify the audience, jurisdiction, project owner, and intended use: class-only, public portfolio, or commercial release.
- [ ] Read the course policy on AI assistance and prepare to disclose use honestly.
- [ ] Check the exact service, account type, plan, privacy notice, and terms of use.
- [ ] Do not paste source code, paid assets, personal data, private keys, credentials, or unpublished work unless you have permission and an approved service.
- [ ] Record the source and licence of any text, image, sound, dataset, or code that you provide as input.

## While generating and editing

- [ ] Keep a dated prompt log with the tool/model, task, prompt, output used, and human edits.
- [ ] Mark which parts were AI-assisted, copied from an external source, or independently written.
- [ ] Make and record real human decisions: edit, select, arrange, test, reject, or add original expression.
- [ ] Ask the tool for source leads, not legal conclusions; open and read the cited sources yourself.
- [ ] Avoid prompts designed to imitate a living artist, named character, protected brand, or specific person's likeness without permission.

## Before publishing or sharing code

- [ ] Search distinctive AI-generated code or text for close matches; treat matching results as a reason to investigate, not as proof of infringement.
- [ ] Review third-party licences. Keep required attribution, notices, source offers, and change notices.
- [ ] Check all direct and transitive dependencies, including their licence files and exceptions.
- [ ] Run tests, static analysis, and security checks. An AI-generated snippet is not verified just because it compiles.
- [ ] Check the current tool terms for output similarity, warranties, data use, and any relevant commercial-use limits.
- [ ] Confirm whether the work contains human-authored expression and avoid overstating ownership or exclusivity.
- [ ] If rights are unclear or the stakes are high, replace the material, seek permission, or obtain qualified advice.
